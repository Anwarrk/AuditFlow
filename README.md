# AuditFlow 🔍

## Overview

AuditFlow is an interactive audit workflow assistant that automates workflow navigation, guides auditors through each audit phase, and supports audit documentation.

The project provides a structured approach to simulate an Information Security Audit process by guiding auditors through planning activities, validation checks, and audit phase progression.

---

## Features

- Interactive audit session initialization
- Auditor and organization information capture
- Audit framework selection:
  - ISO 27001
  - NCA ECC
- Visual audit lifecycle representation
- Planning phase assessment workflow
- Decision-based validation checks
- Finding generation for missing audit requirements
- Audit completion summary
